# sistema-remuneraciones-chile
Sistema profesional de remuneraciones para Chile con cálculos de liquidaciones, impuesto único y gestión de nómina

## Interfaz gráfica (GUI)

El sistema cuenta con una interfaz gráfica profesional construida con `tkinter`,
compatible con Windows 10/11. Para ejecutarla:

```bash
python main.py
```

Se abrirá la ventana principal con menú superior, barra de herramientas, panel
lateral de navegación y acceso a los módulos de Empresa, Trabajadores,
Instituciones Previsionales, Liquidaciones de Sueldo y Reportes.
